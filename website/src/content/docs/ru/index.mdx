  <Card title="ML для временных рядов" icon="puzzle">

  </Card>
  <Card title="Системы низкой задержки" icon="setting">
    Ultra-low-latency архитектура, управление памятью, lock-free структуры данных, TCP tuning, io_uring, CPU affinity, профилирование. Production система на Rust.
  </Card>

## Технологический стек

Каждая глава содержит production-ready код:
- **Rust** — основной язык реализации, высокопроизводительное ядро
- **Julia** — исследования и прототипирование, SDE solvers
- **Python** — ML/DL, PyTorch, scikit-learn, pandas

## Предварительные требования

- Математический анализ и линейная алгебра
- Основы теории вероятностей
- Опыт программирования (любой язык)
